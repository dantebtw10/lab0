###Что такое Git и для чего он используется?
Git - Система контроля версий,используется для просмотра изменений в коде всей командой проекта,также используется для того чтобы 
каждый мог работать над кодом на своем компьютере,также в случае ошибок с новой версией ПО можно откатываться к старой.
###В чём разница между централизованными и распределёнными системами контроля версий?
В централизованной системе существует один главный сервер,где хранится вся история и все разработчики подключаются к нему.
В распределенной версии полная копия всей истории проекта хранится у каждого разработчика на компьютере,что позволяет не боятся сбоев в работе сервера
###Что такое репозиторий в Git?
Репозиторий — это папка проекта, где хранятся все файлы и история их изменений.

1. git init - Создает новый пустой репозиторий в текущей папке.
2. git clone <url> - Копирует удаленный репозиторий к себе на компьютер.
3. git status - Показывает текущее состояние файлов (измененные, добавленные, неотслеживаемые).
4. git add <file> - Добавляет файл в "зону подготовки" (staging area) перед коммитом.
5. git commit -m "message" - Сохраняет изменения из зоны подготовки в историю репозитория с комментарием.
6. git push - Отправляет локальные коммиты на удаленный сервер (GitHub).
7. git pull - Забирает изменения с удаленного сервера и сливает их с вашей версией.
8. git log - Показывает историю коммитов.
9. git branch - Показывает список веток.
10. git checkout <branch> - Переключает на другую ветку.
